## 功能说明

### CLI 使用

```bash
# 基础用法 - 截取当前视口，检测二维码并裁剪
camo qr-screenshot [profileId]

# 完整参数
camo qr-screenshot [profileId] [--output <dir>] [--full] [--padding <px>]
```

- `--output, -o <dir>` — 输出目录（默认 `./screenshots`）
- `--full` — 截取整个页面（默认只截视口）
- `--padding <px>` — 二维码裁剪区域的边距像素（默认 20）
- `--profile, -p <id>` — 指定 profile

### 执行流程

1. 通过 browser service 截图获取 PNG buffer
2. 保存完整截图到 `screenshot_<timestamp>.png`
3. 用 `pngjs` 解码 PNG → `jsqr` 检测二维码（支持正向/反向）
4. 如果检测到二维码：计算四角定位点的 bounding box → 加 padding 裁剪 → 保存 `qrcode_<timestamp>_N.png`
5. 输出 JSON 结果（包含二维码内容、bounds、裁剪路径等）

### Runtime Operation

自动化脚本中可用 `screenshot_qr` action：

```json
{
  "action": "screenshot_qr",
  "params": {
    "fullPage": false,
    "padding": 20,
    "outputDir": "./screenshots"
  }
}
```

返回标准 operation 结果，包含 `qrFound`、`qrCount`、`qrCodes`（含 `qrData` 和 `croppedPath`）。
